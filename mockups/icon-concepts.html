Gitty icon concepts

Four directions for the desktop app icon. All four keep the current dark tile and Gitty's green accent. The small rows show each icon at Dock/taskbar sizes on dark and light backgrounds; 16px is roughly what Windows shows in the taskbar and file lists.

A · Outline

A cat head drawn as one line. The most minimal and calm; reads as a cat at any size. No git hint on its own.

B · Commit ears

The same outline, with git commit dots at the ear tips, so the head becomes a little branch graph. Ties the name together: git + kitty.

C · Branch tail

A sitting cat whose tail forks like a git branch. The most playful and story-like. Details get lost below 32px.

D · Peek

A bold cat peeking over the bottom edge. The strongest at tiny sizes (taskbar, tabs); fills the tile.

  • Colours can change too: the purple in B matches the branch colour in the current icon.
